""" 霧観測データ整理スクリプト（Google Colab用・複数ファイル対応版） -------------------------------------- 処理内容： - 複数のExcelファイルを一括アップロード - 各ファイルに対して整形処理を実行 - 整形後のデータを時系列順に結合して1つのCSVとして出力 使い方： Google Colabでセルごとに上から順番に実行してください。 """ # ============================================================ # セル1：ライブラリの読み込み # ============================================================ import datetime import pandas as pd from google.colab import files # ============================================================ # セル2：Excelファイルのアップロード（複数選択可） # ============================================================ print("📂 アップロードするファイルを選択してください（複数選択可）...") uploaded = files.upload() INPUT_FILES = list(uploaded.keys()) print(f"✅ アップロード完了: {len(INPUT_FILES)} ファイル") for f in INPUT_FILES: print(f" - {f}") # ============================================================ # セル3：設定 # ============================================================ OUTPUT_FILE = "fixed_fog_data_all.csv" # 1日の観測時刻（4:00 〜 19:00） HOURS = list(range(4, 20)) # 時刻列の特殊値 LABEL_NOTHING = "全箇所特になし" LABEL_SICK = "自己の体調不良で観測できず" # ============================================================ # セル4：各処理の関数定義 # ============================================================ def load_data(path: str) -> pd.DataFrame: """Excelファイルを読み込み、不要列を除去して返す。""" df = pd.read_excel(path) # Unnamed列と先頭が数字の列（凡例列）を除去 keep = [c for c in df.columns if not str(c).startswith("Unnamed") and not str(c)[0].isdigit()] df = df[keep].copy() # 日付列を前方補完（各グループの最初の行にしか日付がないため） df["日付"] = df["日付"].ffill() # Excelのシリアル値（数字）を「YYYY/MM/DD」形式の文字列に変換 df["日付"] = pd.to_datetime(df["日付"], origin="1899-12-30", unit="D").dt.strftime("%Y/%m/%d") return df def get_obs_cols(df: pd.DataFrame) -> list: """観測地点列名のリストを返す（日付・時刻列を除く）。""" return [c for c in df.columns if c not in ("日付", "時刻")] def expand_row(row: pd.Series, obs_cols: list) -> list: """ 特殊行（全箇所特になし / 体調不良）を 4:00〜19:00 の16行に展開する。 観測値はすべて NaN（欠損値として機械学習側で扱う）。 """ expanded = [] for hour in HOURS: new_row = row.copy() new_row["時刻"] = datetime.time(hour, 0) for col in obs_cols: new_row[col] = float("nan") expanded.append(new_row) return expanded def fix_fog_data(df: pd.DataFrame) -> pd.DataFrame: """メインの整形処理。""" obs_cols = get_obs_cols(df) result = [] skipped = 0 for _, row in df.iterrows(): jikoku = str(row["時刻"]) if jikoku == LABEL_NOTHING: result.extend(expand_row(row, obs_cols)) elif jikoku == LABEL_SICK: result.extend(expand_row(row, obs_cols)) elif jikoku == "nan": skipped += 1 else: result.append(row) print(f" 空行スキップ数: {skipped}") return pd.DataFrame(result) def validate(df: pd.DataFrame) -> None: """1日あたりの行数が揃っているか確認して報告する。""" counts = df.groupby("日付").size() expected = len(HOURS) ok_days = (counts == expected).sum() bad_days = counts[counts != expected] print(f"\n── 最終検証結果 ──────────────────────") print(f"総行数 : {len(df)}") print(f"総日数 : {len(counts)}") print(f"正常日数 ({expected}行): {ok_days}") if bad_days.empty: print("✅ 全日付で行数が揃っています。") else: print(f"⚠️ 行数が {expected} でない日付:") print(bad_days.to_string()) print("✅ 関数の定義が完了しました。") # ============================================================ # セル5：全ファイルの整形・結合 # ============================================================ all_dfs = [] for filename in INPUT_FILES: print(f"\n読み込み中: {filename}") df = load_data(filename) print(f" 元データ行数: {len(df)}") fixed = fix_fog_data(df) print(f" 整形後行数 : {len(fixed)}") all_dfs.append(fixed) # 時系列順に結合（日付列でソート） print("\n結合・並べ替え中...") combined_df = pd.concat(all_dfs, ignore_index=True) combined_df = combined_df.sort_values(by=["日付", "時刻"]).reset_index(drop=True) validate(combined_df) # ============================================================ # セル6：CSVとして保存してダウンロード # ============================================================ combined_df.to_csv(OUTPUT_FILE, index=False, encoding="utf-8-sig") print(f"\n✅ 保存完了: {OUTPUT_FILE}") print("📥 ダウンロードを開始します...") files.download(OUTPUT_FILE)
